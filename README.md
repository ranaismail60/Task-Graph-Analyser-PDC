# PDC - Task-Graph Analyser

## Overview
This program performs task-dependency graph analysis, calculates topological/concurrency metrics, simulates list-scheduling on `p` processors using the smallest task-number priority rule, and plots Gantt charts with critical path highlighting.

## Prerequisites
- Python 3.x
- Matplotlib (`pip install matplotlib`)

## How to Run
Execute the Python script in your terminal/command prompt:
```bash
python task_graph_analyser.py
